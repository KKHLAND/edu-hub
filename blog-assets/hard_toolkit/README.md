# 쌤의 영어 해설노트(블로그스팟) 고난도 해설 — 모의고사 1회당 3편 (2026-11-15 사용자 확정)
- 파트1: 함축 의미 · 어휘(문맥상 낱말, 장문 어휘 포함) · 어법  예) 3월 고1: 21·29·30·42
- 파트2: 빈칸 추론  예) 31~34
- 파트3: 글의 순서 · 문장 삽입 · 요약문  예) 36~40
- 문항마다: 해설지 이미지(v2_<코드>/q<번호>.png) → 지문 구조 → 정답 근거(영문 핵심 문장+풀이) → 선택지 5개 전부 분석 → 핵심 구문 → 유형 공략법 팁. 순서·삽입은 단서표/위치별 점검표.
- 글 앞: 대표 이미지 + 도입 + 구성 안내 + 요약표(번호·유형·정답·배점·어려운 이유), 글 끝: 공략 3원칙 표, 복습 체크리스트, 3편 시리즈 링크 + 쌤의 이슈노트 '모의고사 해설' 카테고리 링크.
- 섹션 HTML 예시: secs.json (3월 고1 13문항). assemble.py <커밋> '<링크 json>' 로 hard_P1~3.html 생성.
- 블로거: 새 글 → HTML 보기 → CodeMirror setValue → 제목 실제 타이핑 → 맞춤 퍼머링크(mock-<코드>-imp / -blank / -order) 입력 후 Enter, 패널에 주소가 바뀐 것 확인 → 게시 → '확인'은 실제 클릭(JS 클릭 시 퍼머링크가 자동으로 바뀐 적 있음) → 3편 주소 확정 후 시리즈 링크 넣어 각 글 업데이트 → 글 목록 '관리'에서 라벨 5개(2026 <월> 학평, <월> <학년> 모의고사, <학년> 영어, 모의고사 해설, 고난도 문항).

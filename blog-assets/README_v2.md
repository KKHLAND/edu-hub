# 모의고사 해설 새 포맷 (v2, 2026-11-14 사용자 확정)
- 게재처: 티스토리 '쌤의 이슈노트' kkhland.tistory.com → 카테고리 '모의고사 해설' (애드센스 승인 블로그). koreaholic·블로그스팟 해설노트에는 올리지 않음(해설노트는 추후 3점 고난도 전용).
- 모의고사 1회분 = 3편: P1 듣기 1~17 / P2 독해 18~30 / P3 독해 31~45. 어휘만 모은 글 없음.
- 문항마다 이미지 1장(발문·지문 또는 대본·선택지·해석·정답·어휘) + 텍스트(듣기: 핵심/함정, 독해: 쌤의 해설).
- 독해 이미지: 선생님 해설지 PDF(학력평가 폴더 각 시험 폴더의 *_해설지.pdf)를 200dpi로 렌더 → 위·아래 파란 선 사이만 자름(머리글 학번/이름, 원묵고 로고 제외) → 1200px, 16색 PNG. (render 코드: crop 부분은 대화 기록 참고, 파란 선 검출)
- 해설지에 없는 문항(보통 25 도표, 27·28 실용문, 43~45 장문)과 듣기 1~17은 render_cards.py로 같은 좌우 레이아웃 카드 생성: 문제 텍스트는 '한글.hwpx'(문제지), 해석은 '좌지문 우해석.hwpx', 듣기는 *_듣기대본.pdf. 해석이 없으면 교사가 직접 쓰고, 어휘는 10개.
- new_format.py: 본문 HTML(티스토리용은 <!--THUMB-->, <!--IMG:파일|alt--> 자리표시) + 미리보기. 대표 이미지는 thumb.py.
- 발행: 내장 브라우저 kkhland /manage/newpost/ → localStorage '__v2prep'(base 커밋 경로만 바꿔 사용) 또는 같은 절차: 이미지 붙여넣기 업로드로 [##_Image..##] 코드 받기 → 본문 setContent → 제목·태그 → 카테고리 '모의고사 해설' → 본문 실제 클릭+End/스페이스/백스페이스 → 완료 → 공개·예약(날짜·시각)·URL 슬러그·대표 이미지 → 공개 발행 → 캡차는 사용자 입력, 저장 끝날 때까지 탭 이동 금지.
- 티스토리 하루 새 글 5개 한도: 이슈 글 하루 2개(09:07, 13:07) + 모의고사 3편.
- 자산: GitHub KKHLAND/edu-hub blog-assets 브랜치 blog-assets/v2_<코드>/ (jsDelivr 커밋 고정).

- (11/17 사용자 결정) 듣기편은 음원을 직접 넣지 않고, 문항마다 'EBSi 무료 음원 바로가기' 링크(p.ebs-link)만 단다. new_format_g2.py에 반영됨. 독해편에는 넣지 않음.
